# Portfolio Website — Project Roadmap

A living checklist to track progress on my portfolio site, hosted on GitHub Pages.
Check off tasks as you complete them. Add notes as you go.

---

## Phase 1 — Foundation Audit
> Goal: Make sure the existing site is set up correctly before building anything new.

- [x] Confirm repo is named `yourusername.github.io`
- [x] Confirm GitHub Pages is enabled (Settings → Pages)
- [x] Confirm the correct branch (`main`) is being published
- [x] Review current file and folder structure
- [x] Verify live site loads at `https://yourusername.github.io`
- [x] Install VS Code
- [x] Install VS Code extension: **Live Server**
- [x] Install VS Code extension: **Prettier**
- [x] Clone repo to local machine (download it to VS Code)
- [x] Make a small test edit locally and push it to GitHub

## Phase 2 — Clean Structure & Design
> Goal: Organize files properly and write clean, professional HTML and CSS.

- [ ] Reorganize files into a scalable folder structure:
  - `index.html` (home page)
  - `about.html`
  - `projects.html`
  - `contact.html`
  - `css/style.css`
  - `js/main.js`
  - `assets/images/`
- [ ] Write semantic HTML (using proper tags like `<header>`, `<nav>`, `<main>`, `<footer>`)
- [ ] Create a single external stylesheet (`css/style.css`)
- [ ] Build out home page (`index.html`)
- [ ] Build out About page
- [ ] Build out Projects page
- [ ] Build out Contact page
- [ ] Test site on mobile (resize browser window)
- [ ] Check site loads correctly on GitHub Pages after changes

## Phase 3 — Interactivity & Git Workflow
> Goal: Learn proper Git habits and add basic interactivity to the site.

- [ ] Understand the basic Git workflow: commit → push → pull
- [ ] Practice creating a branch before making changes
- [ ] Practice merging a branch back into `main`
- [ ] Set up GitHub Actions for automatic deployment (optional)
- [ ] Add basic JavaScript (e.g. mobile nav menu, smooth scroll)
- [ ] Never edit directly on `main` — always use a branch

**Notes:**


---

## Phase 4 — Grow & Showcase
> Goal: Keep the site growing as skills and projects grow.

- [ ] Add first real project to the Projects page
- [ ] Add second project
- [ ] Check accessibility basics (alt text on images, good color contrast)
- [ ] Look into a custom domain (optional, ~$10–15/year)
- [ ] Explore Tailwind CSS for easier styling (optional)
- [ ] Explore a static site generator like Astro or Eleventy (optional, advanced)
- [ ] Set up Google Search Console (optional, for SEO)
